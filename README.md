# Insight Studios - Cinematic Portfolio

A premium, production-ready website for a high-end film and photography studio.

## Features
- **Smooth Scrolling:** Powered by Lenis.
- **Cinematic Motion:** GSAP and ScrollTrigger for high-performance, GPU-accelerated animations (`clip-path`, `transform`).
- **Contextual Cursor:** Custom cursor with magnetic pull and contextual states (Play, View).
- **Responsive & Accessible:** Fully responsive editorial layouts with `prefers-reduced-motion` support.

## How to Run Locally
You must run this through a local server to prevent CORS issues with external libraries and local assets.
